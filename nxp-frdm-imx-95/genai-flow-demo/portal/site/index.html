Prefer a serial terminal? Manual steps
  1. Open a serial terminal (PuTTY, Tera Term, or the VS Code serial monitor) on the board's MCU-Link COM port at 115200 baud.
  2. Press Enter, and log in as root (no password).
  3. Run ip addr (or ifconfig) and note the board's IP address.
  4. Browse to http://<board-ip>:8088 and drop your kit file on the page.
