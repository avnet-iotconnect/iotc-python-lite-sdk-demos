# Runtime ELFs

Prebuilt runtime binaries are downloaded from S3 by `create-package.sh` if not present locally:

- [tinyml_complex.no_accel.elf](https://s3.us-east-1.amazonaws.com/avnetpublicaccess/large-repo-files/tinyml_complex.no_accel.elf)
- [tinyml_complex.accel.elf](https://s3.us-east-1.amazonaws.com/avnetpublicaccess/large-repo-files/tinyml_complex.accel.elf)

These are required by `create-package.sh`.
